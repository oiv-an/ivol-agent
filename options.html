IVOL Agent

Настройки подключения к API. Ключ хранится только локально в этом браузере.
Список подгружается с /v1/models после ввода ключа.
Когда выбрана отдельная модель, основная получает tool web_search: она формулирует запрос, а поиск выполняет эта модель отдельным вызовом и возвращает выжимку со ссылками. «Как основная» — поиск работает по-старому, внутри запроса основной модели.
Добавляется к базовому промпту на всех сайтах. Промпт для конкретного сайта настраивается в самой панели (кнопка 📝).
