# IVOL Agent — Chrome-расширение

ChatGPT-подобный AI-агент в боковой панели браузера. Видит текущую страницу, заполняет формы, кликает, открывает сайты, ищет в интернете и выполняет JavaScript — с подтверждением каждого опасного действия.

Работает с любым OpenAI-совместимым API (`/v1/responses`, `/v1/models`).

## Установка

```bash
git clone https://github.com/<user>/ivol-agent.git
cd ivol-agent
cp config.example.js config.js
```

Открой [`config.js`](config.example.js:7) и впиши свой `baseUrl` и `apiKey`.

Затем:

1. `chrome://extensions` → включить **Режим разработчика**.
2. **Загрузить распакованное расширение** → выбрать эту папку.
3. Клик по иконке → откроется боковая панель.

Ключ можно задать и через страницу настроек (⚙) — значения из `chrome.storage.local` имеют приоритет над `config.js`.

> `config.js` в `.gitignore`. Ключ остаётся только на твоей машине и никогда не попадает в репозиторий.

## Что умеет

| Действие                                  | Подтверждение                          |
| ----------------------------------------- | -------------------------------------- |
| Прочитать страницу (`get_page_context`)   | нет                                    |
| Прочитать выделенный текст                | нет                                    |
| Скролл к элементу                         | нет                                    |
| Поиск в интернете (нативный `web_search`) | нет                                    |
| Снимок экрана (`take_screenshot`)         | **да**, с объяснением зачем            |
| Заполнить форму                           | **да**, с показом полей и значений     |
| Кликнуть по элементу                      | **да**                                 |
| Открыть URL                               | **да**                                 |
| Выполнить JavaScript                      | **да, всегда**, с показом полного кода |

Для действий уровня «да» можно поставить галку «не спрашивать для этого домена» — разрешение действует только внутри текущей комнаты.

## Комнаты

Каждый чат — отдельная комната с историей и своими разрешениями. Комната привязывается к вкладке и к окну браузера: два окна работают как два независимых агента.

- `☰` — список комнат, поиск, удаление
- `＋` — новая комната

Всё хранится в `chrome.storage.local`, наружу ничего не уходит кроме запросов к твоему API.

## Уровни рассуждений

Внизу панели — селектор модели и уровня рассуждений: `none`, `low`, `medium`, `high`, `xhigh`, `max`.

Какие значения реально поддерживает провайдер — зависит от него. Некоторые прокси молча схлопывают неизвестные значения в `medium`.

## Как это работает

```
Side Panel ──► background service worker ──► POST /v1/responses (stream)
                        │
                        ├─ function_call ──► permission gate ──► карточка в панели
                        │                                              │
                        │                                    Разрешить / Отклонить
                        │                                              │
                        └─ chrome.scripting / chrome.tabs / content.js ┘
```

Agent-loop крутится в service worker, максимум 12 шагов за один запрос. Результат каждого tool возвращается как `function_call_output`, включая случай отказа пользователя — модель это видит и предлагает альтернативу.

Парсер стрима в [`streamOnce()`](background.js:247) поддерживает оба формата ответа: Responses API (`response.output_text.delta`) и Chat Completions (`chat.completion.chunk`). Некоторые прокси принимают вход в формате Responses, но стримят в формате Chat Completions.

При `429/500/502/503/504` — авто-ретрай до 3 попыток с бэкоффом.

## Как агент видит страницу

Гибрид, как у браузерных агентов: основной канал — текст и семантика, картинка по требованию.

1. **`get_page_context`** — очищенный текст + карта интерактивных элементов. У каждого элемента `agent_id`, тип, label, placeholder, значение. Это accessibility-семантика, по которой агент кликает и заполняет формы. Работает всегда, стоит дёшево.
2. **`take_screenshot`** — снимок видимой области через `chrome.tabs.captureVisibleTab`, ужимается до 1024px и JPEG q60. Модель вызывает его сама, когда текста не хватает: график, canvas, картинка без alt, вопрос про вёрстку.

Почему не только скриншоты: клик по `agent_id` детерминирован, клик по координатам — нет; длинные строки (промокоды, артикулы) модель с картинки читает с ошибками.

Технический нюанс: `function_call_output` принимает только текст, поэтому картинка уходит **отдельным сообщением** с `input_image` сразу после результата тула — см. [`runAgent()`](background.js:290).

## Ограничения

- Не работает на служебных страницах `chrome://`, `chrome-extension://` и в Web Store.
- Карта элементов ограничена 400 элементами, текст — 12 000 символов.
- Ключ хранится в `chrome.storage.local` в открытом виде. Это инструмент для личного использования, не публичное расширение для Web Store.
- `run_script` выполняет произвольный JS на странице в `world: "MAIN"`. Всегда читай код в карточке подтверждения перед тем, как разрешить.

## Разработка

```bash
# проверка синтаксиса
for f in *.js lib/*.js; do node --check "$f"; done
```

После правок: `chrome://extensions` → **⟳** на карточке → **закрыть и заново открыть боковую панель** (сама не перерисовывается). Версию видно бейджем внизу панели.

Сброс хранилища: F12 на панели → `chrome.storage.local.clear()` (сотрёт все комнаты).
